# Особисті фінанси — клієнт, частина 3
React + React Router + Vite + SCSS. CRUD категорій, операцій і бюджетів, огляд місяця, статистика заощаджень.
## Запуск клієнта та сервера разом
Node.js 22.12+ або новіший. У server/: npm ci, скопіювати .env.example у .env, npm start. API http://127.0.0.1:3072.
У client/: npm ci, npm run dev. Інтерфейс http://127.0.0.1:5173. Vite проксі /api → http://127.0.0.1:3072. Для окремого хостингу задайте VITE_API_URL і CORS_ORIGIN; preview не використовує dev-проксі.
npm test — гроші, HTTP-помилки, сховище. npm run build — production-збірка.
## Архітектура
FinanceApi та Preferences інжектуються через ServicesProvider. Dashboard і ResourcePage — контейнери стану; компоненти окремими файлами, SCSS окремо для кожного. HashRouter — навігація. localStorage зберігає лише обраний місяць. Гроші — цілі копійки, фінансові дані зберігає сервер.
## Межі
Локальний навчальний прототип без авторизації. Серверні залежності мають відомі попередження аудиту частини 2. Повна браузерна перевірка та звіт ще в роботі.
