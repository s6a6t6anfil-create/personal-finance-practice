# Personal Finance API — частина 2
Продовження системи особистих фінансів із частини1: облік доходів/витрат, бюджети та заощадження. Python CLI залишається у корені; сервер — окремий Node.js модуль із новою схемою категорій. Бази CLI і сервера різні; автоматичного перенесення старих даних немає.

## Стек
Node.js22+, Express5, SQLite, Sequelize6, Umzug3 (міграції), Awilix DI, Zod, CORS, morgan, Swagger UI/OpenAPI3.0.3. package-lock.json фіксує залежності.

## Запуск
```sh
cd server
npm ci
cp .env.example .env
npm run migrate
npm start
```
Відкрити http://127.0.0.1:3072/docs/ — Swagger; /openapi.json — специфікація. У .env налаштовуються HOST, PORT, DB_PATH, CORS_ORIGIN. База створюється локально. Міграції виконуються один раз, історія — SequelizeMeta. Можна пропустити окремий migrate: старт також застосовує нові міграції.

## API
Для categories, transactions, budgets:
- GET /api/{resource}: список; GET /api/{resource}/{id}: один запис.
- POST /api/{resource}: створення201.
- PUT /api/{resource}/{id}: повна заміна200.
- DELETE /api/{resource}/{id}: видалення204.
GET /api/reports?month=2026-10 — місячні підсумки; GET /health — перевірка запуску.
Грошові суми — цілі копійки UAH від1до1 000 000 000. Дати YYYY-MM-DD, місяці1900–9998. Категорії1–80символів, примітка≤500. Категорія має операції та бюджети; її видалення заборонено за наявності пов’язаних записів409. Бюджет унікальний за(categoryId,month). Доходи мінус витрати — розрахункові заощадження; null при відсутності бюджету або доходів для відповідних показників.

## Перевірки
```sh
npm test
npm run postman
```
25 інтеграційних тестів; колекція docs/postman.json —26запитів/28assertions. Newman потребує запущеного сервера й окремої порожньої тестової бази. Колекція створює і прибирає свої демонстраційні записи; не запускати на робочих фінансових даних. baseUrl можна змінити у Postman або через --env-var baseUrl=http://127.0.0.1:3072.

## Шари
src/routes.js → controllers.js (Zod) → services.js → repositories.js → Sequelize/SQLite. container.js реєструє репозиторії, singleton-сервіси та logger в Awilix. app.js збирає middleware й централізовану обробку помилок. migrations/001-finance.js має up/down у транзакції.

## Межі
Однокористувацький локальний навчальний сервер; типовий HOST127.0.0.1. Авторизація, шифрування, банки, пагінація й великі обсяги не реалізовані. CORS не є захистом доступу. Не публікувати сервер з реальними фінансами без додаткового захисту. Логи пишуться в stdout (за потреби npm start > server.log 2>&1); тіла запитів і суми операцій не записуються. DELETE безповоротний.
